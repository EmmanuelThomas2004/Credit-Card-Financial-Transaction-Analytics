## Instructions
1. Open the respective Google Drive folder.
2. Download the required dataset.
3. Use the raw data for profiling and cleaning.
4. Use the cleaned data for SQL analysis and Power BI reporting.

**Note:** Dataset files are hosted externally because of their large size and are not directly stored in this GitHub repository.
